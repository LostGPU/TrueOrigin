# TrueOrigin

TrueOrigin is a school project exploring the design of a premium chocolate brand website. It was created as a frontend development exercise focused on product presentation, responsive layouts, and ways to explain cocoa sourcing.

## What the project explores

- A multi-page chocolate shop concept with seven product varieties.
- Shared page components and a product catalogue.
- German and English interface text, plus light and dark themes.
- A browser-based cart and product-specific map views.
- OpenStreetMap maps showing illustrative cocoa routes.

## Project status

This is a school prototype, not a real shop. Product details, article numbers, availability, and supply-chain routes are illustrative. The routes are plausible examples, not verified TrueOrigin sourcing information; they do not represent confirmed suppliers, production sites, or the origins of other ingredients.

The cart is a frontend demonstration. The project does not accept orders or process payments.

## Built with

- HTML
- CSS
- JavaScript
- Leaflet and OpenStreetMap
